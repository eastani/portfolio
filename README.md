# Naoya Higashitani Portfolio

Bilingual EN/JA portfolio site for industrial data engineering, predictive
maintenance, and AI solution work.

Live site: https://eastani.github.io/portfolio/

## Overview

This portfolio presents my work at the intersection of industrial sensor data,
AI, and product reliability. It is designed as a concise public profile for
data engineer, data scientist, and industrial AI roles.

The site highlights:

- Industrial data engineering and IIoT experience
- Predictive-maintenance and anomaly-detection work
- Quality analytics and operational telemetry analysis
- Cross-border R&D collaboration in Japanese and English
- A public reference project using NASA's CMAPSS turbofan dataset

## Featured Project

### Predictive Maintenance on NASA CMAPSS

Repository: https://github.com/eastani/predictive-maintenance-cmapss

An end-to-end Python pipeline for remaining useful life prediction on NASA's
CMAPSS turbofan degradation dataset. The project includes strict data loading,
feature engineering, baseline and XGBoost models, executed Jupyter notebooks,
tests, and GitHub Actions CI.
