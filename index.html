About Me

into Operational Intelligence

I'm a Data Engineer with hands-on experience building end-to-end data pipelines for industrial equipment monitoring and predictive maintenance. My work centers on extracting, contextualizing, and operationalizing sensor data to deliver measurable business impact.

At Hitachi High-Technologies, I contributed to predictive maintenance projects involving time-series sensor analysis, anomaly detection, and ML-driven failure forecasting for precision manufacturing equipment — handling everything from data ingestion design to dashboard delivery.

I'm passionate about bridging the OT/IT gap in heavy industries, and I thrive in environments where data engineering and domain expertise combine to create real-world reliability improvements.

Demo Project

Predictive Maintenance Pipeline

A simulated end-to-end predictive maintenance system modeled after real industrial use cases. Using the NASA CMAPSS turbofan degradation dataset as reference, this demo illustrates the full data-to-insight journey: sensor ingestion, anomaly detection, RUL prediction, and health monitoring.

All data is synthetically generated for demonstration — no proprietary information is used.

Python Plotly scikit-learn XGBoost Docker GitHub Actions Azure Data Factory

Scenario

Rotating industrial equipment (pump / compressor) monitored across 300 operating cycles. Three sensors — vibration, temperature, pressure — feed a real-time health scoring model. When the health score drops below 30%, a maintenance alert is triggered.
